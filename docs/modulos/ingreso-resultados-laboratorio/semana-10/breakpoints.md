# Semana 10: Breakpoints

| Rango | Decision |
|---|---|
| 320-359 px, movil pequeno | Una columna; barcode/prueba en dos lineas; acciones ancho completo; tabla se vuelve tarjetas. |
| 360-430 px, movil estandar/grande | Una columna; tipo y unidad pueden compartir fila si conservan 44 px de toque. |
| >=431 px | Mantener el mismo orden hasta tablet; en >=768 px una tabla de pendientes puede recuperar columnas. |

Solo se usan estos rangos porque el flujo se resuelve en una columna; no hay contenido adicional que justifique breakpoints intermedios. Teclado sigue orden visual y el foco visible no cambia por ancho.
